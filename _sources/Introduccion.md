# Introduccion

Este dataset de Kaggle ofrece una base de datos sobre carros usados a la venta, los datos se consiguieron usando tecnicas de web scrapping y provee informacion relevante de precio, condicion, manofacturera entre otras. El dataset provee informacion suficiente para poder realizar modelos de machine learning, para nuestro caso, Ridge y Lasso

Registros: 426,880 carros usados a la venta

Campos: 36 características
